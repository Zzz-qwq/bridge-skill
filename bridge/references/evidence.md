# 来源核查

路径和具体机会分开核实。某个平台有某类参与方式，只能说明这种路径存在。推荐某个当前入口时，应读取该活动、项目、任务或岗位自己的页面。

优先顺序：主办方规则、项目维护者的贡献说明和任务、雇主招聘页、官方平台目录。聚合目录与搜索结果用于发现线索，再回到实际来源。必要时记录来源链接、读取日期、页面标题与支持关键说法的段落。

对具体入口逐项核查：

- **做什么**：活动、任务或岗位要求的实际产出与参与步骤。
- **谁能参与**：身份、地区、年龄、团队、经验与设备要求；未见规定就写“未核实”，不推断“人人可参加”。
- **何时能参与**：报名或认领状态、开始和截止日期；网页发布日期不等于截止日期。
- **投入什么**：时间、费用、算力、语言与所需技能；未标费用不能写成免费。
- **留下什么**：作品、贡献、模拟任务记录、证书等按实际性质表述；参与不等于录取、获奖或雇佣。

输出时把已核实事实、个人适配判断和未知项分开。适配判断应说明依据用户的哪些条件。过期、已关闭、任务已被认领或门槛不符的入口，不描述成现在可以直接参加。若官方页面无法读取，标记当前状态不明并给用户核查路径。

## 社交平台上的线索

用户不知道机会名称时，先提出可尝试的平台和具体搜索式，例如“目标岗位 + 实习 + 城市”“公司名 + 岗位 + 招聘”“领域 + 远程实践”。社交平台的优势是可能出现招聘网站之外的线索；它不保证某家公司当前在那里招聘。搜索到的帖子先记录原链接、发布者、发布日期、申请方式，再尽量去招聘方官方渠道交叉核对。帖子不能读时，请用户提供公开链接或截图；仅凭搜索摘要、转述或模型记忆，不列出具体公司为当前机会。

小红书[账号开放平台权限说明](https://openaccount.xiaohongshu.com/docs/scope)于 2026-11-09 显示：该账号接口目前开放的是基础用户信息，读取笔记仍处于规划中。这不等于小红书所有开放能力或所有公开网页都不可用，也不能把该接口当作已经接通的完整实时笔记库。
