# 入口地图

以下官方资料已于 2026-11-09 阅读，用来帮助用户发现不同参与方式。链接是继续核查的入口，并非当日开放的比赛、岗位或任务保证。回答时根据用户目标选择少数相关类别，解释具体角色和成果；若要推荐某个当前机会，按 [来源核查](evidence.md) 阅读该机会自己的规则页面。

| 参与方式 | 可探索的官方入口 | 可以做什么、留下什么 |
| --- | --- | --- |
| 为开源项目贡献 | [GitHub 贡献指南](https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github) | 除写代码，还可复现问题、测试、完善文档；留存 issue、讨论或合并记录。到具体仓库核对贡献规范与任务状态。 |
| 发布可体验的 AI 作品 | [Hugging Face Spaces](https://huggingface.co/docs/hub/spaces-overview) | 制作小型交互 Demo，记录用途、实现、评测与迭代；实际资源和费用按方案核查。 |
| 公开分析或挑战 | [Kaggle Notebooks](https://www.kaggle.com/docs/notebooks)、[竞赛规则说明](https://www.kaggle.com/docs/competitions) | 写可复现实验或按一场比赛的规则提交作品；先看个人能力、数据许可和该活动时间。 |
| 黑客松 | [Devpost 活动目录](https://devpost.com/hackathons)、[提交说明](https://help.devpost.com/article/126-know-your-submission-steps) | 在限定时间内组队或个人做作品，留下提交页与演示；资格和开放状态由活动页决定。用户已知道黑客松时，优先探索其他类别。 |
| 中文社区共建 | [Datawhale 组织](https://github.com/datawhalechina)、[机遇清单](https://github.com/datawhalechina/DOPMC/blob/main/OPPORTUNITY.md) | 可寻找 AI 工具教程、学习内容或项目贡献；具体课题是否仍需人，查看维护者当前说明。 |
| 开发者社区实践 | [华为开发者空间创作广场](https://developer.huaweicloud.com/developerspace/usersquare.html) | 官方展示了 AI Agent 案例共创与产品体验官参与方式；可探索原创实践文章、产品体验与反馈。当前活动是否招募及内容要求要进入当期页面核查。 |
| 职业模拟 | [Forage 模拟目录](https://www.theforage.com/simulations) | 体验模拟工作任务，留存实际完成的分析或成果；必须如实称为模拟，不算受雇或实习。 |

用户可以不依赖外部招募，先做一个自己定义的小作品、真实工具评测或案例分析。这是自主实践，不应包装为主办方项目。平台名称仅是进入方式，实际价值来自用户承担的任务和可审阅的成果。
