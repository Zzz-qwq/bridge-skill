# Bridge

**让机会不再只属于知道机会的人。**

Bridge 是一个对话 Skill。用户说出想完成的事，或一个尚不清楚如何探索的兴趣，它先回应眼前需求，再展示几条机制不同、用户可能没想到的路，并给出可尝试的第一步。实习、AI 入门和动漫兴趣是首批验证场景；娱乐与好奇心不必被转成求职任务。

## 当前状态

这是内测候选版。Skill 已在码道 IDE 中成功加载过。实习输入能自动调用 Bridge；首轮动漫输入未调用，已扩展触发描述和兴趣探索规则，等待在码道复测。具体机会的实时核查和真实用户效果仍待验证。不要将入口地图中的平台视为当前正在招募的机会。

## 使用

将 [`bridge/`](bridge/) 放到宿主的项目技能目录。在码道 IDE 中，可直接描述目标或兴趣；若宿主没有自动调用，可明确要求“使用项目级 bridge 技能”。示例：

> 我在找 AI 产品实习，每周能投入 3 小时。除了黑客松，还有什么方式能留下可展示的实践成果？

> 最近想找点好看的动漫。除了常见的热门榜单，还有什么方式能找到合我口味的作品？

Skill 的完整规则在 [`bridge/SKILL.md`](bridge/SKILL.md)。若宿主无法读取当前网页，Bridge 应标明机会状态与参与条件尚未核实，并给出仍能执行的自主实践第一步。

## 原则

- 不替用户决定人生。
- 不虚构机会、资格或成功路径。
- 区分来源事实、适配判断和尚未核实的信息。
- 让用户自己确认哪条路径是新发现，再选择下一步。
