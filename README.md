# Bridge

**让机会不再只属于知道机会的人。**

Bridge 是一个对话 Skill。用户说出想完成的事，它帮助用户发现几条机制不同的可行路径，解释每条路径为什么有用、可以留下什么成果，以及从哪里开始。大学生求职与 AI 入门是首批验证场景，Skill 不限于这两类用户。

## 当前状态

这是内测候选版。Skill 已在码道 IDE 中成功加载过，但不同对话的原生调用稳定性、具体机会的实时核查和真实用户效果仍待验证。不要将入口地图中的平台视为当前正在招募的机会。

## 使用

将 [`bridge/`](bridge/) 放到宿主的项目技能目录。在码道 IDE 中，可尝试明确要求“使用项目级 bridge 技能”，然后描述目标、已知路径和可投入条件。示例：

> 我在找 AI 产品实习，每周能投入 3 小时。除了黑客松，还有什么方式能留下可展示的实践成果？

Skill 的完整规则在 [`bridge/SKILL.md`](bridge/SKILL.md)。若宿主无法读取当前网页，Bridge 应标明机会状态与参与条件尚未核实，并给出仍能执行的自主实践第一步。

## 原则

- 不替用户决定人生。
- 不虚构机会、资格或成功路径。
- 区分来源事实、适配判断和尚未核实的信息。
- 让用户自己确认哪条路径是新发现，再选择下一步。
